# Генератор чеков и документов

Консольное приложение на Python 3.11+ ищет HTML-шаблоны и источники данных CSV/JSON во всех вложенных папках проекта, проверяет плейсхолдеры `{{имя_поля}}` и сохраняет отдельные HTML/PDF в `output/`. Файлы в `.git`, `.venv`, `venv`, `__pycache__` и `output` при поиске пропускаются. Шаблоны и данные можно сочетать произвольно, если поля совместимы.

## Установка

Создайте виртуальное окружение и установите Python-зависимости:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

На Windows WeasyPrint требует Pango и связанные DLL. `pacman` — команда MSYS2: её нельзя запускать в PowerShell или обычной командной строке Windows.

1. Установите MSYS2 с настройками по умолчанию с [официального сайта](https://www.msys2.org/).
2. В меню «Пуск» откройте **MSYS2 UCRT64** (не PowerShell и не MSYS2 MSYS) и выполните там:

```bash
pacman -S mingw-w64-ucrt-x86_64-pango
```

3. После завершения установки вернитесь в PowerShell, перейдите в папку приложения, создайте виртуальное окружение и установите Python-зависимости командами выше. Если Python не находит DLL, задайте в PowerShell путь к библиотекам MSYS2 и проверьте установку:

```powershell
$env:WEASYPRINT_DLL_DIRECTORIES = 'C:\msys64\ucrt64\bin'
python -m weasyprint --info
```

На macOS:

```bash
brew install weasyprint
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m weasyprint --info
```

Если macOS не находит Pango, добавьте Homebrew-библиотеки в `DYLD_FALLBACK_LIBRARY_PATH` (обычно `/opt/homebrew/lib` на Apple Silicon или `/usr/local/lib` на Intel). PDF использует системные шрифты с резервным стеком Arial/Liberation Sans/sans-serif. Для гарантированной кириллицы установите Roboto или Liberation Sans. Сам HTML-шаблон может подключать локальные CSS, изображения и шрифты относительными путями.

## Запуск

Из этой папки:

```bash
python generate_receipts.py
```

При запуске приложение рекурсивно находит HTML-шаблоны и CSV/JSON-файлы. В меню рядом с именем файла показывается понятное русское название, например `Акт оказанных услуг (service_act.html)`; полные пути не выводятся. После выбора шаблона список источников данных отфильтровывается: остаются только читаемые CSV/JSON, в которых есть все поля этого шаблона. Если совместимых файлов нет, приложение сообщает об этом. Клавиша `U` обновляет список после добавления файлов.

После выбора источника можно выбрать одну запись, несколько (`1,3`), диапазон (`1-5`) или все (`A`). Перед созданием отображаются данные выбранных записей. Для каждой создаются HTML и PDF в `output/`. После сохранения программа предлагает открыть первый PDF, все PDF или папку результата и остаётся доступной для следующей генерации.

Для обычной работы запустите приложение без дополнительных параметров. В меню выберите шаблон, затем совместимый файл CSV или JSON, после этого — нужную запись. Можно выбрать несколько записей, диапазон или все сразу. Перед генерацией приложение покажет данные для проверки.

Чтобы посмотреть, какие шаблоны и файлы данных найдены, запустите приложение с параметром `--list`.

Для запуска без меню задайте в командной строке шаблон через `--template`, источник через `--csv` или `--json`, а записи — одним из способов:

- `--row` — одна запись по номеру;
- `--rows` — несколько номеров через запятую или диапазон, например `1,3` или `2-5`;
- `--all` — все записи.

Нумерация записей начинается с 1; строка заголовков CSV не считается записью. Приложение проверит, что в источнике есть все поля шаблона. Для пакетной генерации оно продолжит работу, даже если одна запись вызовет ошибку, и покажет итог успешных и неуспешных операций. PDF при запуске без меню автоматически не открываются. Папку проекта и место сохранения результатов можно задать параметрами `--root` и `--output`.

## Добавление шаблонов и данных

Поместите `.html`/`.htm`, `.csv` и `.json` в любую папку внутри проекта. Имена колонок CSV или ключи JSON должны совпадать с плейсхолдерами шаблона, например `{{id}}`, `{{amount}}`. Значения экранируются для HTML. CSV должен быть в UTF-8 (допускается BOM), с разделителем запятая или точка с запятой. JSON читается из массива объектов, одиночного объекта или из массива внутри поля `records`, `data`, `items` либо `documents`. Вложенные массивы и объекты JSON подставляются как компактный JSON-текст. Поле `id` используется в имени файла; если его нет, используется порядковый номер записи.

Образцы включают:

- чек прихода — `templates/receipts/receipt_income.html` и `test_data/receipts/income.csv`;
- счёт и накладную — HTML-шаблоны и CSV-наборы в `templates/documents/` и `test_data/documents/`;
- акт услуг и авансовый отчёт — HTML-шаблоны с соответствующими примерами JSON в тех же папках.

JSON может быть массивом объектов, одиночным объектом или объектом с массивом записей в поле `records`, `data`, `items` либо `documents`. Например:

```json
{
  "records": [
    {"id": "ACT-01", "client": "ООО Пример", "amount": 12000}
  ]
}
```

```bash
python -m unittest discover -s tests -v
```

Интеграционный тест PDF пропускается, если WeasyPrint или системные зависимости недоступны. Тесты не запускают приложения для просмотра PDF.
